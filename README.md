## 📖 О проекте

**Травяная Лавка** — небольшой интернет-магазин травяных чаёв и лечебных сборов.

Проект объединяет простой современный frontend и backend на **FastAPI**.

Пользователь может:

- просматривать каталог травяных чаёв;
- фильтровать товары по категориям;
- добавлять товары в корзину;
- видеть количество товаров и итоговую стоимость;
- использовать промокод;
- заполнить данные для доставки;
- выбрать способ оплаты;
- оформить заказ;
- сохранить заказ в базе данных SQLite.

---

## ✨ Возможности

### 🫖 Каталог товаров

Каждый чай содержит:

- название;
- состав;
- описание эффекта;
- цену;
- изображение;
- категорию.

Категории:

- 🛡️ Иммунитет и тонус
- 🌙 Расслабление и сон
- 🍃 Очищение и детокс

---

### 🛒 Корзина

Корзина позволяет:

- добавлять товары;
- подсчитывать количество позиций;
- рассчитывать итоговую стоимость;
- оформлять заказ через модальное окно.

---

### 🎁 Промокоды

В проекте реализована система промокодов.

Например:

```text
tsaritsino
```

или

```text
царицыно
```

Промокод предоставляет скидку:

```text
30%
```

Итоговая стоимость дополнительно пересчитывается на backend.

---

### 📦 Оформление заказа

Перед созданием заказа пользователь указывает:

- имя;
- номер телефона;
- адрес доставки;
- способ оплаты.

После подтверждения информация отправляется в FastAPI и сохраняется в **SQLite**.

Каждому заказу база данных автоматически присваивает уникальный `ID`.

Для хранения информации используется **SQLite**.

Файл базы данных:

```text
app/database/teas.db
```

Подключение создаётся в:

```text
app/database/session.py
```

```python
Base.metadata.create_all(bind=engine)
```

## 🌐 API

Основной префикс API:

```text
/api/v1
```

### Получить список чаёв

```http
GET /api/v1/teas
```

Пример ответа:

```json
[
  {
    "id": 1,
    "name": "Таёжный иммунитет",
    "ingredients": "Иван-чай, шиповник, листья брусники, кедровая хвоя",
    "effect": "Укрепляет защитные силы организма",
    "price": 350,
    "image_url": "...",
    "category": "immune"
  }
]
```

---

### Получить чай по ID

```http
GET /api/v1/teas/{tea_id}
```

Например:

```http
GET /api/v1/teas/1
```

---

### Создать заказ

```http
POST /api/v1/orders
```

Пример тела запроса:

```json
{
  "total_price": 740,
  "items_count": 2,
  "promo_code": "tsaritsino",
  "customer_name": "Иван Иванов",
  "customer_phone": "+79991234567",
  "customer_address": "г. Москва, ул. Ленина, д. 1",
  "payment_method": "card"
}
```

Пример ответа:

```json
{
  "status": "success",
  "order_id": 1,
  "final_sum": 518,
  "message": "Заказ успешно принят!"
}
```

## 🚀 Запуск проекта

### 1. Клонировать репозиторий

```bash
git clone <URL_РЕПОЗИТОРИЯ>
```

Перейти в папку проекта:

```bash
cd <НАЗВАНИЕ_ПРОЕКТА>
```

---

### 2. Создать виртуальное окружение

Windows:

```bash
python -m venv .venv
```

Активировать:

```bash
.venv\Scripts\activate
```

---

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

---

### 4. Запустить FastAPI

```bash
uvicorn app.main:app --reload
```

После запуска сайт будет доступен по адресу:

```text
http://127.0.0.1:8000
```
